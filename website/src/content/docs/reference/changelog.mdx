## Release process

```bash
# Add a changeset to your PR:
pnpm changeset

# Merge to main — CI opens a "Version Packages" PR automatically.
# Merge that PR — CI publishes to npm in topological order.
```

See [CONTRIBUTING.md](https://github.com/DavideCarvalho/nestjs-inertia/blob/main/CONTRIBUTING.md) for the full release flow.
