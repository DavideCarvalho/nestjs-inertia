## Install core + Vite

<Tabs>
  <TabItem label="pnpm">
    ```bash
    pnpm add @dudousxd/nestjs-inertia @dudousxd/nestjs-inertia-vite
    pnpm add -D @dudousxd/nestjs-inertia-codegen
    ```
  </TabItem>
  <TabItem label="npm">
    ```bash
    npm install @dudousxd/nestjs-inertia @dudousxd/nestjs-inertia-vite
    npm install --save-dev @dudousxd/nestjs-inertia-codegen
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add @dudousxd/nestjs-inertia @dudousxd/nestjs-inertia-vite
    yarn add -D @dudousxd/nestjs-inertia-codegen
    ```
  </TabItem>
</Tabs>

## HTTP adapter

NestJS defaults to Express. If you use Fastify, install the Fastify adapter instead.

### Express (default)

<Tabs>
  <TabItem label="pnpm">
    ```bash
    pnpm add express
    pnpm add -D @types/express
    ```
  </TabItem>
  <TabItem label="npm">
    ```bash
    npm install express
    npm install --save-dev @types/express
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add express
    yarn add -D @types/express
    ```
  </TabItem>
</Tabs>

### Fastify

<Tabs>
  <TabItem label="pnpm">
    ```bash
    pnpm add fastify @fastify/cookie @nestjs/platform-fastify
    ```
  </TabItem>
  <TabItem label="npm">
    ```bash
    npm install fastify @fastify/cookie @nestjs/platform-fastify
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add fastify @fastify/cookie @nestjs/platform-fastify
    ```
  </TabItem>
</Tabs>

## Peer dependencies

| Peer dep | Required by | Condition |
|----------|-------------|-----------|
| `@nestjs/common >=10` | core | always |
| `@nestjs/core >=10` | core | always |
| `express >=4` | core | Express adapter (default) |
| `fastify >=4` | core | Fastify adapter |
| `vite >=5` | vite | build pipeline |
| `@nestjs/testing >=10` | testing | test suites |
| `typescript >=5` | codegen | CLI static analysis |

## Optional packages

Install only what you need.

<Tabs>
  <TabItem label="pnpm">
    ```bash
    # Typed HTTP client + <Link> components
    pnpm add @dudousxd/nestjs-inertia-client

    # Test helpers (expectInertia, InertiaTestingModule)
    pnpm add -D @dudousxd/nestjs-inertia-testing
    ```
  </TabItem>
  <TabItem label="npm">
    ```bash
    npm install @dudousxd/nestjs-inertia-client
    npm install --save-dev @dudousxd/nestjs-inertia-testing
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add @dudousxd/nestjs-inertia-client
    yarn add -D @dudousxd/nestjs-inertia-testing
    ```
  </TabItem>
</Tabs>

## Engine requirements

All packages require **Node.js >= 20**. NestJS 10 and 11 are both supported.
