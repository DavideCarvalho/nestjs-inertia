## How it works

The codegen reads your NestJS controllers and generates a fully typed API client in `.nestjs-inertia/api.ts`. No contracts, no schemas, no manual type definitions — it infers everything from your existing code.

Every controller method gets:
- **`queryOptions()`** (GET routes) — for `useQuery`
- **`mutationOptions()`** (POST/PUT/PATCH/DELETE routes) — for `useMutation`
- **`queryKey()`** — for `invalidateQueries` / `setQueryData`

Response types use `Awaited<ReturnType<import('...').Controller['method']>>` — TypeScript infers the return type directly from your controller method. No explicit return type annotation needed.

## Queries

```tsx
import { useQuery } from '@tanstack/react-query';
import { api } from '~codegen/api';

// Simple query
const { data: crew } = useQuery(api.crew.getCrew.queryOptions());

// Query with params
const { data: posts } = useQuery(api.posts.list.queryOptions({ page: 2 }));

// Conditional query (spread pattern)
const { data } = useQuery({
  ...api.users.show.queryOptions(),
  enabled: !!userId,
});
```

## Mutations

```tsx
import { useMutation } from '@tanstack/react-query';
import { api } from '~codegen/api';

const createPost = useMutation(api.posts.create.mutationOptions());

// Body is fully typed from the controller's @Body() parameter
await createPost.mutateAsync({ title: 'Hello', content: '...' });
```

## Cache invalidation

```tsx
import { useQueryClient } from '@tanstack/react-query';
import { api } from '~codegen/api';

const queryClient = useQueryClient();

// Typed key — no magic strings
queryClient.invalidateQueries({ queryKey: api.crew.getCrew.queryKey() });

// With params
queryClient.invalidateQueries({ queryKey: api.posts.list.queryKey({ page: 2 }) });
```

## Route helper

For parameterized URLs (e.g. `/users/:id`), use the `route()` function with `fetcher`:

```ts
import { fetcher } from '~codegen/api';
import { route } from '~codegen/routes';

// When mutationOptions() can't handle URL params
const result = await fetcher.patch(route('crew.updateCrew', { id: userId }), {
  body: { name: 'New Name' },
});
```

## Route.* type helpers

Extract request/response types from any route:

```ts
import type { Route } from '~codegen/api';

type CrewData = Route.Response<'crew.getCrew'>;
type CreateBody = Route.Body<'posts.create'>;
type ListQuery = Route.Query<'posts.list'>;
```

## Advanced: defineContract + @ApplyContract

For cases where you want explicit Zod schemas with runtime validation (not just type extraction), you can still use the contract pattern. See the [Codegen guide](/nestjs-inertia/guides/codegen/#applycontract-example).
