Static-analysis CLI that reads your NestJS controllers and Inertia page components, then emits fully typed TypeScript files.

## Exports

| CLI / Export | Description |
|--------------|-------------|
| `nestjs-inertia codegen` | One-shot generation |
| `nestjs-inertia codegen --watch` | Watch mode; re-generates on file changes |
| `nestjs-inertia init` | Scaffold config, HTML shell, Vite config, entry point, patch `nest-cli.json` for Docker |
| `nestjs-inertia doctor` | Diagnose shell template, `nest-cli.json` assets, tsconfig paths, package versions, codegen output, Vite config |
| `nestjs-inertia doctor --fix` | Auto-fix diagnosable issues |
| `defineConfig(config)` | Type-safe config helper |
| `generate(config)` | Programmatic API |
| `watch(config, onChange?)` | Programmatic watch API |
| `loadConfig(cwd?)` | Load and resolve `nestjs-inertia.config.ts` |

## Generated files

| File | Contains |
|------|----------|
| `pages.d.ts` | Module augmentation for typed `@Inertia()` and page props |
| `routes.ts` | Typed route map + `route()` helper for URL resolution |
| `api.ts` | `queryOptions()`, `mutationOptions()`, `queryKey()`, `infiniteQueryOptions()` per route |

Response types use `ReturnType<import(...)>`. Page props use `Parameters<typeof import(...).default>[0]`.

## Doctor checks

`nestjs-inertia doctor` validates your project setup. All checks with a fix icon can be auto-fixed with `--fix`:

| Check | Auto-fixable |
|-------|:---:|
| `nestjs-inertia.config.ts` exists | Yes |
| Shell template (rootView) file exists | Yes |
| `nest-cli.json` copies shell template to `dist/` (Docker) | Yes |
| `.nestjs-inertia/` codegen output exists | Yes |
| `tsconfig.json` has `@/*` path alias | Yes |
| Core packages installed and on same version | Yes |
| `@inertiajs/*` is v3+ | Yes |
| `.gitignore` includes `.nestjs-inertia/` | Yes |
| `package.json` has `build:client` script | Yes |
| `vite.config.ts` has `resolve.alias` and nestInertia plugin | No |

See [Codegen guide](/docs/guides/codegen) for full configuration and output reference.
